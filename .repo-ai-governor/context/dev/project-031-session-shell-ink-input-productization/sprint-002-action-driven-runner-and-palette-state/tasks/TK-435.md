## 1. 目标

把 `CliSessionShellReadlinePromptAdapter` 正式退化为 fallback seam，并收口 Ink close / EOF / SIGINT cleanup。

## 2. Acceptance

1. 默认 TTY path 不再依赖 readline 作为 foreground input owner。
2. fallback seam 仍能承接 multiline 或 non-TTY 保底路径。
3. Ink interrupt / EOF 不应把 session shell 变成进程级失败。

## 3. Execution Notes

1. 2026-03-30：`shouldUseInkInput()` 已作为默认分流条件注入 runner constructor。
2. 2026-03-30：`CliSessionShellInkRunner.close()`、interrupt queue 与 EOF resolution 已稳定，`readline` 仅在 fallback / multiline 路径保留。
