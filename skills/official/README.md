# Official Skills Package

This directory is the bundled official skill package root for `Repo AI Governor`.

Current purpose:

1. provide a stable catalog entrypoint
2. define the official on-disk skill package layout
3. serve as the source for future `skills install / list / doctor`

Notes:

1. The catalog is stored at `catalog.json`.
2. Individual skill directories will be added under this root.
3. Shared assets are stored under `../shared/`.
