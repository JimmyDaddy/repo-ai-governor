# TK-951 设计自动化控制器模型与执行状态机

- Status: todo
- Priority: P0
- Project: `automation-v1`
- Sprint: `sprint-001`
- Owner: Architecture
- Due: 2026-03-20
- Depends On: `none`

## Goal

定义自动化执行的核心控制模型，明确模式切换、阶段推进、暂停/继续/中止语义，以及门禁输入输出契约。

## Deliverables

1. 自动化控制器模型文档（模式、状态、转移条件）
2. `run` 请求与执行上下文的数据契约草案
3. 高风险动作目录与门禁触发接口约定
4. `stage -> surface` 路由模型（含回退与冲突规则）
5. `surface preflight` 契约（安装/授权/探活检查与失败处理）

## Acceptance

1. 明确 `manual / assisted / autonomous` 三种模式边界与转换规则。
2. 状态机可表达 `start -> stage -> gate -> continue/stop` 的闭环。
3. 可表达多 AI 分工路由（例如 `solution_review=claude-code`、`implementation=codex`、`code_review=github-copilot`）。
4. 可表达 preflight 通过/失败后的流转策略。
5. 后续 `TK-952`、`TK-953` 可以直接复用该模型进行实现。

## Notes

1. 该任务是本 sprint 的设计基线，后续任务依赖其结论。
