# TK-952 实现 `run` 命令最小编排能力

- Status: done

- Owner: Core Runtime
- Due: 2026-03-21
- Depends On: `TK-951`

## Goal

新增统一的自动化执行入口 `run`，在受控模式下串联治理阶段，替代人工逐条命令拼接。

## Deliverables

1. `run` 命令注册与参数定义
2. 阶段选择与串行编排执行逻辑
3. 结构化执行结果输出（summary/markdown/json）
4. 阶段路由解析与执行入口分发逻辑（`stage -> surface`）
5. preflight 执行器（检查 surface 可用性并输出降级/阻断决策）

## Acceptance

1. 支持最小执行路径，例如：`repo-ai-governor run --mode assisted --project <project> --sprint <sprint>`。
2. 失败时可定位到阶段，并返回稳定退出码。
3. 支持 `--dry-run` 预览编排结果，不执行副作用操作。
4. 支持三入口分工执行场景：`codex` 写代码、`claude-code` 方案 review、`github-copilot` 代码 review。
5. 默认先执行 preflight；必需 surface 不可用时终止并给出可操作提示。
