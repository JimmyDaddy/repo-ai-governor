# TK-957 增加流程配置校验与解释命令入口

- Status: todo

- Project: `automation-v1`
- Sprint: `sprint-001`
- Owner: DX/Runtime
- Due: 2026-03-27
- Depends On: `TK-952`, `TK-956`

## Goal

为自定义编排提供“先校验再执行”的安全入口，降低用户在复杂流程配置下的试错成本。

## Deliverables

1. 增加流程解释入口（例如 `run --explain-process`），输出已编译流程。
2. 增加流程校验入口（例如 `run --validate-process`），只做编译与校验，不做阶段派发。
3. 输出包含配置错误定位信息（冲突 routeKey、非法 stageId、loop 配置异常等）。
4. Quick Start 或 automation 文档补充自定义流程校验示例。

## Acceptance

1. `--explain-process` 能稳定输出当前生效流程（默认或自定义）。
2. `--validate-process` 在配置无效时返回非 0，并给出可操作错误信息。
3. 校验模式下不触发真实任务执行与副作用写入。
4. 新选项与现有 `--dry-run`、`--format` 兼容。

## Notes

1. 该任务优先服务“项目初次接入自定义流程”的落地体验。
