# TK-902 修复 npm 安装后 `init` 首次上手可用性

- Status: done
- Priority: P0
- Project: `release-ops`
- Sprint: `sprint-001`
- Owner: Release
- Due: 2026-03-19
- Depends On: `TK-901`

## Goal

修复 `npx @cjhdev/repo-ai-governor init` 在空目录首次执行时的可用性问题，确保新用户初始化后可以立即进入可执行状态。

## Deliverables

1. `init` 支持 npx 场景依赖自安装（写入 `package.json` 并安装 `@cjhdev/repo-ai-governor`）。
2. `.repo-ai-governor` 的关键目录不再是空壳，提供默认说明文件。
3. `init` 后自动安装官方 skills（默认针对启用 adapter）。
4. 补齐命令选项、测试与执行记录。

## Acceptance

1. 在空目录执行 `npx @cjhdev/repo-ai-governor init` 后，`package.json` 存在且 `devDependencies` 包含 `@cjhdev/repo-ai-governor`。
2. `.repo-ai-governor/adapters`、`.repo-ai-governor/slots`、`.repo-ai-governor/templates`、`.repo-ai-governor/reports` 均包含可读说明文件。
3. 官方 skills 会落到目标 surface 的默认目录（例如 `.codex/skills/`）。
4. 测试 `test/commands/init-command.test.js` 和全量 `npm run check` 通过。

## Notes

1. 设计与实现细节回写到 sprint checklist 和 CSV。
2. 自安装可通过 `--skip-self-install` 跳过，skills 自动安装可通过 `--skip-skill-install` 跳过。
