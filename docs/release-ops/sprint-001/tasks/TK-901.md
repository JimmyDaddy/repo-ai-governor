- Depends On: `none`

## Goal

把当前仓库的发布链路从“已有 GA gate 和远端 workflow 骨架”推进到“具备 `release-it` 与 publish CI 的正式自动化基线”。

## Deliverables

1. `release-it` 配置与 npm script
2. npm publish GitHub Actions workflow
3. 对齐现有 release readiness checks
4. 对应测试与实现摘要

## Acceptance

1. 可以通过 `npm run release` 调用 `release-it`
2. publish workflow 在 `release.published` 上触发，并先执行现有门禁
3. workflow 使用 npm registry 与发布凭据完成 publish
4. 自动化测试覆盖关键字段与步骤

## Notes

1. 实现摘要见 [../release-it-publish-ci.md](../release-it-publish-ci.md)。
2. 当前 workflow 采用 npm Trusted Publishing 推荐模式，发布前需要在 npm 后台将本仓库与 `.github/workflows/publish-npm.yml` 绑定。
