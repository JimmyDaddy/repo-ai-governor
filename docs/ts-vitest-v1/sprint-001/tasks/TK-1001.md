# TK-1001 建立 TypeScript 工程与构建基线

## Goal

为仓库建立可执行的 TypeScript 工程基础，支持类型检查和构建输出，不影响现有 CLI 行为。

## Deliverables

1. TypeScript 依赖与 `tsconfig*` 配置
2. `typecheck/build` npm scripts
3. `dist` 构建输出策略与入口映射说明

## Acceptance

1. 可以执行 `npm run typecheck`
2. 可以执行 `npm run build`
3. 构建产物可以支持 CLI 启动路径

## Notes

1. 当前阶段采用 `allowJs=true` 的过渡编译策略，先建立 `src/bin -> dist` 构建通路，后续在 `TK-1003` 逐步推进 `.js -> .ts` 迁移。
2. `build` 流程增加运行时资产复制：`schema JSON`、`skills`、`package.json`，确保 `dist` 入口可独立运行。
