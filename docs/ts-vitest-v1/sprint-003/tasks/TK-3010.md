# TK-3010 收敛 command/runtime 显式 `any` 存量并分批类型化

- Status: completed
- Priority: P1
- Project: `ts-vitest-v1`
- Sprint: `sprint-003`
- Owner: Core
- Due: 2026-04-22
- Depends On: `TK-3008`

## Goal

针对 `src/commands` 中历史遗留的显式 `any`（重点 `run/check/plan/init`）进行分批类型化收敛，在不改变现有行为的前提下提升类型安全与可维护性。

## Deliverables

1. 输出 `explicit any` 存量盘点与批次拆分计划
2. 分批替换 `run/check/plan/init` 中可收敛的 `: any` 与 `as any`
3. 保持现有治理门禁和回归测试通过

## Batch Plan

1. `EA-B1` Baseline & Typed Primitives
   - 固化 `run-command` 头部基础工具函数参数/返回类型
   - 收敛明显可替换的 `content/locale/path` 基础 `any`
2. `EA-B2` Run Workflow/Routing Typing
   - 收敛 `run-command` 中 `processModel/routingPlan/workflowResult/runState` 主链路 `any`
   - 优先替换 stage/routing/checkpoint 恢复路径
3. `EA-B3` Check/Plan/Init Residual Cleanup
   - 收敛 `check-command.ts`、`plan-command.ts`、`init-command.ts` 的 `any`
   - 通过复用 `src/types` 现有契约减少局部断言
4. `EA-B4` Regression & Guardrail
   - 关键命令测试回归与门禁验证
   - 评估是否将 `noExplicitAny` 从 warning 收紧为 error（仅评估，不在本任务强制变更）

## Acceptance

1. 目标文件 `src/commands/{run,check,plan,init}-command.ts` 的显式 `any` 总量从基线显著下降（当前基线 129）
2. `check-command.ts`、`plan-command.ts`、`init-command.ts` 达到零显式 `any`
3. `npm run typecheck`、关键命令测试、`npm run check` 通过
