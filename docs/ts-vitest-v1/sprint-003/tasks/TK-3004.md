# TK-3004 建立覆盖率基线并引入阈值门禁

- Status: todo

- Project: `ts-vitest-v1`
- Sprint: `sprint-003`
- Owner: QA
- Due: 2026-04-11

## Goal

形成覆盖率“可观测 + 可约束”机制，为核心模块设置最低阈值并纳入质量门禁，避免回归时覆盖率静默下滑。

## Deliverables

1. 输出核心模块覆盖率基线快照
2. 定义全局或分层覆盖率最低阈值策略
3. 将覆盖率阈值校验接入门禁命令

## Acceptance

1. `test:coverage` 结果可被门禁消费
2. 阈值配置可解释且与当前基线匹配
3. 覆盖率低于阈值时可明确失败原因
