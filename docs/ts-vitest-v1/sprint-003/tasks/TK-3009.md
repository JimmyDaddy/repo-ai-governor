# TK-3009 收敛 utils-reuse whitelist 存量并清零 legacy util 豁免

- Status: completed
- Priority: P1
- Project: `ts-vitest-v1`
- Sprint: `sprint-003`
- Owner: Core
- Due: 2026-04-16
- Depends On: `TK-3001`, `TK-3008`

## Goal

将 `scripts/governance/utils-reuse-whitelist.json` 当前承接的 5 条 `legacy util baseline` 豁免转化为可执行迁移批次，逐步迁入 `execution_notes` 复用评估记录并清空 `allowList`。

## Deliverables

1. 完成 `utils-reuse` 白名单签名到迁移批次的全量映射
2. 为每个签名补齐可审计的复用评估记录（`execution_notes`）
3. 完成 `allowList` 清零并保持 utils-reuse gate 持续通过

## Batch Plan

1. `UR-B1` Baseline Inventory（5 签名）
   - `src/utils/common.ts#cloneValue`
   - `src/utils/common.ts#isPlainObject`
   - `src/utils/common.ts#normalizeLocale`
   - `src/utils/common.ts#toRelativePath`
   - `src/utils/common.ts#translateLocale`
2. `UR-B2` Execution Notes Backfill
   - 在 `docs/ts-vitest-v1/sprint-003/execution_notes.md` 为 5 个签名补齐 `util` 与 `reuse-eval` 记录
   - 标注复用结论与“保留/不新增重复实现”的理由
3. `UR-B3` Whitelist Cleanup & Gate Verification
   - 将 `scripts/governance/utils-reuse-whitelist.json` 的 `allowList` 收敛为 `[]`
   - 保留并校验 `executionNotesPath` 指向有效
   - 完成 utils-reuse 与 code-standards 门禁回归

## Acceptance

1. 5 条白名单签名全部映射到明确批次并有执行记录
2. `utils-reuse-whitelist.json` 的 `allowList` 清零，且无新增临时豁免
3. `node ./scripts/governance/check-utils-reuse-governance.js --format=json` 返回 `status=pass`

## Risks

1. 若仅清空 `allowList` 但 `execution_notes` 未完整记录，utils-reuse gate 会立即失败
2. 后续若重构 `src/utils/common.ts` 导致签名变化，需要同步更新 `execution_notes` 记录

## Progress

1. 已完成 `UR-B1` 基线盘点：`check-utils-reuse-governance --format=json` 确认 `src/utils/common.ts` 共 5 个导出函数，且与 `legacy util baseline` 豁免签名一一对应（`functionCount=5`、`newFunctionCount=0`）。
2. 已完成 `UR-B2` 记录回填：在 `docs/ts-vitest-v1/sprint-003/execution_notes.md` 追加 5 个 util 签名的复用评估记录（`util + reuse-eval`），确保签名可被门禁检索。
3. 已完成 `UR-B3` 白名单清理：`scripts/governance/utils-reuse-whitelist.json` 的 `allowList` 已清零（`[]`），`executionNotesPath` 继续指向 sprint 执行记录文件。
4. 验证通过：`node ./scripts/governance/check-utils-reuse-governance.js --format=json`、`npm run test -- test/governance/utils-reuse-gate.test.ts`、`node ./scripts/governance/check-code-standards.js --standards code_standards.md`。
