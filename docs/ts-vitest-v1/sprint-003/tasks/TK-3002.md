# TK-3002 将 Biome format/lint 接入默认 gate 与 CI 质量门禁

- Status: completed
- Priority: P0
- Project: `ts-vitest-v1`
- Sprint: `sprint-003`
- Owner: Core
- Due: 2026-04-09
- Depends On: `TK-3001`

## Goal

将 Biome 从“可选执行”升级为“默认质量门禁的一部分”，保证格式与静态规则在本地和 CI 一致执行。

## Deliverables

1. 将 `format:check` 与 `lint` 纳入稳定 gate 执行路径
2. 收敛当前高优先级 Biome 诊断并形成治理策略
3. 更新 CI 质量流水线与门禁文档说明

## Acceptance

1. 本地与 CI 对 Biome 结果一致
2. `npm run check` 能覆盖 Biome 关键校验
3. 无新增规则回归噪音导致的误报阻断

## Progress

1. 已将 `npm run check` 升级为 `format:check -> lint -> build -> check:code-standards` 串行门禁，Biome 校验默认纳入本地质量入口。
2. 已批量收敛历史 Biome 诊断：执行 `biome check --write` 与 `biome check --fix --unsafe`，统一格式、导入排序与高频风格规则。
3. 已将 `suspicious.noExplicitAny` 调整为 `warn` 作为迁移期策略，避免在存量改造完成前阻断主流程。
4. 已为 `test/config/schema.test.ts` 增加 Biome override（禁用 organize imports）以保证 `// @ts-nocheck` 固定在首行，避免 TypeScript 误报回归。
5. 已完成闭环验证：`npm run format:check`、`npm run lint`、`npm run check`、`npm run ci:quality` 全部通过。
