# TK-2004 迁移 cli runtime commands 到 TypeScript

- Status: done
- Priority: P0
- Project: `ts-vitest-v1`
- Sprint: `sprint-002`
- Owner: Core
- Due: 2026-04-01
- Depends On: `TK-2002`, `TK-2003`

## Goal

将 CLI 主执行链路迁移到 TypeScript，收敛命令上下文、错误模型和输出协议类型。

## Deliverables

1. `src/cli/**` 与 `src/commands/**` 迁移到 `.ts`
2. 保持命令参数与输出格式兼容
3. 更新相关命令测试

## Acceptance

1. CLI 主链路迁移后 `npm test` 通过
2. `npm run check` 与 `npm run release:ga-check` 通过
3. 无命令协议破坏性变更
