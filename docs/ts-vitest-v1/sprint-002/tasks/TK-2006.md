# TK-2006 增加 TS-only 审计门禁并收口发布约束

- Status: done
- Priority: P0
- Project: `ts-vitest-v1`
- Sprint: `sprint-002`
- Owner: Release
- Due: 2026-04-03
- Depends On: `TK-2004`, `TK-2005`

## Goal

将“非必要不使用 JS”从约定升级为可执行门禁，建立 JS 残留白名单审计与发布前强校验。

## Deliverables

1. 新增 JS 残留审计脚本与白名单机制
2. 将审计集成到 `check/release` 门禁链路
3. 迁移收口文档与后续约束说明

## Acceptance

1. 新增 JS 文件会被门禁识别并提示
2. 白名单范围明确且最小化
3. `npm run check` 与 `npm run release:ga-check` 持续通过

## Progress

1. 已新增 TS-only 审计脚本与白名单配置：`scripts/governance/check-ts-only-residue.js`、`scripts/governance/ts-only-whitelist.json`，默认审计 `src/**` 与 `test/**` 并支持 `allowList` 豁免。
2. 已将门禁接入检查链路：新增 `package.json` 脚本 `check:ts-only`，并将 `node ./scripts/governance/check-ts-only-residue.js` 纳入 `code_standards.md` 验证命令。
3. 已将约束接入发布链路：`scripts/release/check-release-ready.js` 的 `requiredChecks` 新增 `npm run check:ts-only`，发布自检报告可见 TS-only 要求。
4. 已补充回归验证：新增 `test/governance/ts-only-gate.test.ts` 覆盖“通过/违规/白名单放行”场景，同时更新 `test/release/release-distribution.test.ts` 验证发布门禁检查项。
5. 最终验证通过：`npm run typecheck`、`npm run test -- test/governance/*.test.ts test/release/release-distribution.test.ts test/ci/ci-scripts.test.ts`、`npm run check`、`npm run test`、`npm run test:coverage`、`npm run release:ga-check`。
