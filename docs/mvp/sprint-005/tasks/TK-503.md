# TK-503 提供 CI 调用命令与退出码约定

- Status: done
- Priority: P0
- Project: `mvp`
- Sprint: `sprint-005`
- Owner: CLI
- Due: 2026-04-19
- Depends On: `TK-206`, `TK-501`

## Goal

为当前 CLI 提供稳定的非交互式调用方式与退出码说明，让 `check`、`review`、`review-verify`、`report` 等能力可以直接被 CI 编排。

## Deliverables

1. 非交互式运行参数约定
2. 退出码文档
3. CI 调用示例

## Acceptance

1. CI 可直接调用核心命令
2. 失败时返回非零退出码
3. 文档能覆盖主命令的推荐调用顺序和失败处理
