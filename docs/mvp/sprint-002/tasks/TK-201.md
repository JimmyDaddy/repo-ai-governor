## Goal

定义可表达治理流程阶段、输入输出和门禁条件的流程模板模型，为后续 Governance Engine 和 `plan / check / review` 命令提供统一结构。

## Deliverables

1. 阶段模型
2. 输入/输出定义
3. 门禁字段

## Acceptance

1. 能表达“方案 -> 拆解 -> 开发 -> 自测 -> 评审 -> 评审复核 -> 任务记录回写”
2. 支持串行执行
3. 与现有 CLI 和 sprint 产物规范兼容
