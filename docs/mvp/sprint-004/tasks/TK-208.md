## Goal

实现 `review-verify` 命令，对 `review` 结果执行复核，把复核结论追加回同一份 CR 文件，并推进状态到 `verified_review_<slug>.md` 或后续 `resolved_review_<slug>.md`。

## Deliverables

1. 评审复核入口
2. 复核结论模型
3. 回写与重命名逻辑

## Acceptance

1. 能对 review 结果进行复核
2. 将复核结论追加回同一 CR 文件
3. 支持将文件更新为 `verified_review_<slug>.md`
4. 支持后续流转到 `resolved_review_<slug>.md`
