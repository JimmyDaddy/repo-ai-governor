# AI 开发治理工具 MVP Issue 清单

- 文档版本：v0.1
- 状态：草案

- 关联文档：[product-requirements.md](./product-requirements.md)、[mvp-execution-plan.md](./mvp-execution-plan.md)

## 1. 说明

这份文档把 MVP 执行计划进一步拆成可直接录入任务系统的 issue 清单，默认采用以下约定：

1. `EPIC` 表示能力域。
2. `TK-xxx` 表示可执行任务。
3. 默认优先级使用 `P0 / P1 / P2`。
4. `DoD` 表示该 issue 的最小完成标准。

## 2. 建议迭代顺序

建议按以下顺序推进：

1. 先完成 CLI 底座和配置系统。
2. 再完成流程模板、标准规范和基础报告。
3. 然后补齐插槽机制。
4. 最后完成三类入口适配和 CI 接入收尾。
