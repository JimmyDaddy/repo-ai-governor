## Goal

将依赖产物注册与解析能力接入运行时编排链路，实现“产物生成即注册、任务执行前自动注入上下文”。

## Deliverables

1. 阶段产物自动注册到 Artifact Registry（支持版本与状态更新）。
2. 阶段执行前按 `depends_on_artifacts` 解析依赖并注入执行上下文。
3. 依赖缺失/失效时联动 Policy Gate 触发 `block/escalate/warn`。
4. 回写审计事件字段（producer/consumer/dependency_resolution_status）。
