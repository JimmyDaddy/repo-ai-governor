- Status: todo

- Due: 2026-08-04

## Goal

将依赖产物完整性检查接入发布门禁，在依赖缺失、版本不兼容或状态失效时阻断关键流程。

## Deliverables

1. 在 CI/发布链路接入依赖产物完整性检查命令或等价检查步骤。
2. 将检查策略从 warning 切换为 blocking（非零退出码阻断）。
3. 输出机器可读与人类可读检查结果，便于审计与定位。
4. 与既有依赖边界门禁、版本策略门禁形成组合门禁策略。
