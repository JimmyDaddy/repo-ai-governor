# Getting Started Acceptance Record

## Goal

Validate that a first-time user can install `repo-ai-governor`, bootstrap a repository, run the minimal governance flow, and produce a report within a short trial window.

## Steps

1. Install from local tarball or published package
2. Run `init`
3. Run `doctor`
4. Run `plan`
5. Run `check`
6. Run `report`
