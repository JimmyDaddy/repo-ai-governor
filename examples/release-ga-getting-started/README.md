# Release GA Getting Started Kit

This directory provides the stable assets for the `release-ga / sprint-001 / TK-704` ten-minute onboarding path.

Contents:

1. `request.md`
   - sample requirement input for `plan`
2. `acceptance-record-template.md`
   - template used by the acceptance script
3. `../../scripts/release/run-getting-started-check.sh`
   - end-to-end smoke script for local install + bootstrap + governance validation

Recommended run:

```bash
./scripts/release/run-getting-started-check.sh
```
